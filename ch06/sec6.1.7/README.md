
## Projects

As we have remarked several times throughout this chapter in the repository:
what happens when LLMs now enters the area of programming?
Here you are expected to reflect on this in relation to Section 6.1.7.


### 1. Craftsmanship After Abundance

Question: What happens to craft when competence becomes cheap?

##### Core idea:
LLMs drastically lower the cost of producing "acceptable" output.
This project explores how craftsmanship survives when baseline competence is abundant.

Work to do:
- Compare pre-LLM craftsmanship (scarcity of skill) with post-LLM craftsmanship (scarcity of judgment).
- Reframe craftsmanship as:
- problem framing
- taste
- restraint
- ethical responsibility
- Argue that execution skill is no longer the primary differentiator.

##### Deliverable:
A conceptual model: Craft as judgment under abundance.



### 2. The New Risk: False Fluency

Question: How does LLM assistance create a new kind of stagnation?

##### Core idea:
Your text talks about falling behind by not adopting tools.
This project flips it: what if adopting LLMs causes illusory progress?

Work to do:
- Define "false fluency": producing outputs without understanding.
- Analyze how LLMs can:
- mask conceptual gaps
- discourage slow thinking
- erode mental models
- Contrast:
- inefficiency from old tools
- fragility from over-reliance on new ones

##### Deliverable:
An extension to the "Risks" section:
\subsubsection*{False Fluency and Cognitive Atrophy}



### 3. Craft as Resistance, Not Refusal

Question: What does it mean to resist without becoming obsolete?

##### Core idea:
Craftsmanship is not blind adoption, but selective resistance.
This project articulates when not using LLMs is a craft decision.

Work to do:
- Identify domains where:
- slowness matters
- ambiguity matters
- accountability matters
- Define "intentional friction" as a craft practice.
- Explore parallels with:
- hand tools vs power tools
- analog photography
- live performance

##### Deliverable:
A decision framework: When using an LLM weakens the craft outcome.



### 4. Leadership in a Post-Expert World

Question: How does influence change when everyone has access to expert-level text?

##### Core idea:
Your text links craftsmanship to leadership. This project examines
leadership when authority no longer comes from knowing answers.

Work to do:
- Analyze how LLMs flatten expertise hierarchies.
- Redefine technical leadership as:
- asking better questions
- recognizing bad outputs
- setting epistemic norms
- Explore mentorship when juniors can outperform seniors in speed.

##### Deliverable:
A rewritten version of "Loss of Influence and Leadership" from the book,
adapted for the LLM era.



### 5. The Craft Loop vs the Prompt Loop

Question: Is prompting a craft, or a shortcut around craft?

##### Core idea:
This project compares two learning loops:
- the traditional craft loop (struggle -> feedback -> mastery)
- the prompt loop (request -> output -> adjust phrasing)

Work to do:
- Map both loops explicitly.
- Identify what each loop trains:
- craft loop trains understanding
- prompt loop trains delegation
- Ask whether they can coexist without one hollowing out the other.

##### Deliverable:
A diagrammatic essay contrasting learning vs orchestration.



### 6. Redefining "Keeping Up"

Question: What does continuous learning mean when tools learn faster than humans?

##### Core idea:
The book text assumes learning is about "acquiring new tools."
This project challenges that assumption.

Work to do:
- Argue that "keeping up" now means:
- maintaining epistemic clarity
- updating mental models of agency
- understanding tool limits
- Frame adaptability as meta-learning, not tool chasing.

##### Deliverable:
A revised definition of craftsmanship on continuous learning, for the LLM age.



### 7. Craftsmanship as Moral Responsibility

Question: Does automation raise the ethical bar for craftsmen?

##### Core idea:
When output is easy, responsibility shifts upstream.

Work to do:
- Explore responsibility for:
- correctness
- bias
- downstream effects
- Argue that LLM use increases, not decreases, ethical burden.
- Connect craftsmanship to stewardship, not productivity.

##### Deliverable:
A new subsection from the book: Responsibility Under Automation.
